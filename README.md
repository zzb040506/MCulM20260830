# 多元文化建模 Cross-Cultural Knowledge Modeling

> 一套从 WVS-7 全量题项出发,经由自建编码体系、中层理论注册到跨国可视化与个体画像的**文化知识建模基础设施**。
> 把文化从"一张国籍标签"重新定义为"高维、概率、结构化的特征空间"。

🌐 **在线可视化网站**：<https://mculm20260830.streamlit.app/>
📦 **代码仓库**：<https://github.com/zzb040506/MCulM20260830>

## 一、项目概述

本项目以 **WVS（World Values Survey）第 7 波** 完整数据集为基础（66 国、97,220 名受访者、611 个变量），构建了一条从「题项原子化编码」到「文化图式/中层理论」再到「跨国可视化与个体画像」的完整分析链。它不是单纯的问卷整理,而是在尝试建立一个**可比较、可审计、可扩展**的文化知识建模体系。

项目的核心命题:把文化从"你是哪国人"(确定性、二值、静态)升级到"你在什么文化情境下,如何思考与行动"(概率性、连续、动态)。

### 核心价值

- 底层:WVS 290 题原子化与标准化编码
- 中层:语义字典与中层理论注册
- 上层:文化图式、边界、框架与叙事的结构判断
- 应用:国家文化画像、文化测评题库、文化覆盖/缺口分析、LLM 文化理解能力评估

## 三、方法论框架

### 3.1 六层框架

依据 `跨文化知识建模核心框架`,每道题被视为一个可拆解的文化命题:

$$
U_i = (C_i, D_i, O_i, J_i \mid X_i)
$$

多个单一命题进一步组成跨命题结构:

$$
S_g = \text{Structure}(U_1, \dots, U_n)
$$

| 代码 | 层级 | 核心问题 | 条数 |
| --- | --- | --- | ---: |
| **C** | 核心价值维度 | 依据什么价值方向判断 | 15 |
| **D** | 制度与生活场域 | 判断发生在哪里 | 8 |
| **O** | 文化判断对象 | 谁或什么被判断 | 20 |
| **J** | 判断与关系规则 | 进行了什么类型的判断 | 11 |
| **S** | 跨命题文化结构 | 多题如何组织成图式/边界/框架 | 7 |
| **X / V** | 情境条件 / 价值取向 | 受到哪些情境约束 | 13 / 4 |

### 3.2 关键方法原则

- **国家不等于文化**:国家只是参照总体,不是固定文化本体
- **区分单题与结构**:单题只能作指标,结构判断须基于多题联合分布、条件依赖、文本关系或实验效应
- **可审计**:每条编码均带 `confidence`(high/medium)与 `review_status`(PASS / ADJUDICATED_* / *_AUDIT)

### 3.3 工作链

```
290 题原子命题 → 按 J/O/D/C/V/S 编码 → 按 JODCV 模式分组
            → 34 条中层理论 → 检验证据/反证 → 文化图式 S
```

## 六、多元文化画像数据集

### 6.1 七维文化特征向量

将文化重新定义为高维特征向量:

$$
C_i = [d_{\text{地区}}, d_{\text{语言}}, d_{\text{价值}}, d_{\text{规范}}, d_{\text{关系}}, d_{\text{宗教}}, d_{\text{社会经}}]
$$

每个维度不是单一取值,而是**概率分布/特征向量**,使系统可做软匹配:不是问"他是哪国人",而是问"他的这句话最接近哪个文化特征向量组合"。

### 6.2 为什么选择 WVS

| 优势 | 说明 |
| --- | --- |
| 样本规模最大 | 97,220 个体,是 GLOBE 的 5.6 倍 |
| 国家覆盖最广 | 66 国,涵盖发达/发展中/转型经济体 |
| 变量最丰富 | 611 个变量,可构造 7 维 ~91 个特征 |
| 个体层级数据 | 每个受访者完整问卷,可做个体聚类与软分配 |
| 理论体系成熟 | 内嵌 Inglehart-Welzel 体系 |
| 外部指标已合并 | V-Dem / Freedom House / WGI / BTI / 世行宏观已按国家合并 |

### 6.3 全流程脚本

`多元文化画像数据集/code/` 提供 step1 → step7 完整流程:

| 脚本 | 功能 |
| --- | --- |
| `step1_features.py` | 从 WVS 提取 7 维特征(91 个变量) |
| `step2_gmm.py` | 高斯混合模型拟合 + BIC 选型 |
| `step3_country_dist.py` | 计算各国原型分布 |
| `step4_visualize.py` | 雷达图、热力图、Inglehart 地图 |
| `step5_world_map_viz.py` | 七维世界地图可视化 |
| `step6_cluster_viz.py` | 聚类中心与 PCA/t-SNE 投影 |
| `step7_dimension_stats.py` | 各维度统计表 |

输出位于 `多元文化画像数据集/result/`,包含 `culture_features.parquet`、`culture_prototypes.json`、`country_7dimensions.csv`、`prototype_assignment.parquet` 以及 8 张主图。

## 七、应用场景

- **国家文化画像**:为 66 国输出可比较的文化特征向量与原型分布
- **文化测评题库构建**:基于标准化编码体系扩展题库
- **文化覆盖/缺口分析**:识别哪些文化内容缺少足够题项支持
- **文化社会学解释框架**:从单题编码上升到中层理论与文化图式
- **LLM 文化理解能力评估**:作为标准化参照,检验大模型对文化分布与文化结构的恢复能力
- **全球化产品设计**:替代"按国家切版本"的粗颗粒做法,改用文化特征向量做软匹配
