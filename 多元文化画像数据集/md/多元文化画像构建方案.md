# 多元文化画像构建方案

## 基于 WVS Wave 7 的"文化特征向量"工程化设计

> **核心命题**:把文化从"一张国籍标签"重新定义为"一个高维、概率、结构化的特征空间",使文化理解从"你是谁"转向"你在什么文化情境下,如何思考与行动"。

---

## 一、项目定位与目标

### 1.1 问题意识

传统跨文化研究以"国籍"作为文化的代理变量,存在三重根本缺陷:

| 缺陷类型 | 表现 | 后果 |
|---|---|---|
| **同国异质** | 上海陆家嘴 90 后海归 vs 云南村寨 70 后,同属"中国"但文化行为差异巨大 | 组内方差被国籍均值掩盖 |
| **跨域同质** | 新加坡华人、硅谷工程师、柏林艺术生可能比本国同胞更接近 | 跨国聚类错失真实文化群落 |
| **动态性** | 全球化、移民、数字媒体让文化身份快速流变 | 静态国名无法捕捉演化 |

### 1.2 解决方案

构建 **7 维文化特征向量**:

$$
C_i = [d_{\text{地区}}, d_{\text{语言}}, d_{\text{价值}}, d_{\text{规范}}, d_{\text{关系}}, d_{\text{宗教}}, d_{\text{社会经济}}]
$$

每个维度不是单一取值,而是 **概率分布 / 特征向量**,使得:

- 同一个体在不同情境下可"激活"不同文化子画像
- 一个群体呈现统计分布而非同质整体
- 系统可做软匹配而非硬分类

### 1.3 项目目标

| 层级 | 目标 | 交付物 |
|---|---|---|
| **L1 数据层** | 基于 WVS Wave 7 构建可计算的文化特征库 | 97,220 × 7维 清洗后数据集 |
| **L2 模型层** | 训练文化画像模型(聚类、降维、分布建模) | 文化原型库 + 个体软分配 |
| **L3 应用层** | 提供 AI 交互/产品设计/研究的接口 | 文化指纹查询 + 情境适配建议 |

## 二、数据基础:WVS Wave 7 适配性评估

### 2.1 数据集概况

- **样本**:97,220 人,覆盖 66 个国家/地区,2017–2023 调查
- **变量**:611 个,其中问卷题项 373 个,外部合并指标 238 个
- **缺失率**:94% 的变量缺失率 < 10%,核心价值观题几乎无缺失
- **权重**:含 `W_WEIGHT`(设计权重)与 `S018`(等权国家权重),支持跨国比较

### 2.2 七维度变量映射表

下表给出每个文化维度对应的 WVS 变量,以及构造方式。

#### 维度 1:地区 / 地理

| 子维度 | WVS 变量 | 说明 | 处理方式 |
|---|---|---|---|
| 国家 | `B_COUNTRY_ALPHA` | ISO-3 国别 | one-hot 或 embedding |
| 国内区域 | `N_REGION_ISO` / `N_REGION_NUTS2` | ISO/NUTS 区域码 | 层级编码 |
| 城乡 | `H_URBRURAL` | 1=城市,2=农村 | 二值 |
| 城镇规模 | `G_TOWNSIZE` / `G_TOWNSIZE2` | 人口规模分层 | ordinal |
| 地理坐标 | `O1_LONGITUDE` / `O2_LATITUDE` | 经纬度 | 连续值,可做空间聚类 |

**输出特征**:`d_地区 = [country_emb, region_emb, urban_score, townsize, lat, lon]`

#### 维度 2:语言

| 子维度 | WVS 变量 | 说明 | 处理方式 |
|---|---|---|---|
| 访谈语言 | `S_INTLANGUAGE` / `LNGE_ISO` | ISO 语言码 | one-hot / embedding |
| 国语 vs 母语差异 | (由 `B_COUNTRY` × `S_INTLANGUAGE` 推断) | 是否用非官方语言受访 | 衍生二值 |

> ⚠️ WVS 不直接采集"母语",但访谈语言可作近似。若需更精细的母语/使用语言数据,需外接 Ethnologue 或用户自报数据。

**输出特征**:`d_语言 = [lang_emb, lang_official_flag]`

#### 维度 3:价值维度

这是 WVS 最核心的模块,直接使用 Inglehart-Welzel 体系。

| 子维度 | WVS 变量 | 说明 | 含义 |
|---|---|---|---|
| 世俗-传统 | `SACSECVAL` | 0=传统/宗教,1=世俗理性 | Inglehart 主轴 |
| 生存-自我表达 | `RESEMAVAL` | 0=生存取向,1=自我表达 | Inglehart 第二轴 |
| 权威服从 | `I_AUTHORITY` | 对权威的服从度 | 传统 vs 自主 |
| 民族主义 | `I_NATIONALISM` | 国家自豪与排他 | 包容 vs 排他 |
| 虔诚度 | `I_DEVOUT` | 宗教虔诚 | 世俗 vs 神圣 |
| 自主性 | `I_INDEP` + `I_IMAGIN` + `I_NONOBED` → `AUTONOMY` | 个人自主 | 集体 vs 个人 |
| 平等观 | `I_WOMJOB` + `I_WOMPOL` + `I_WOMEDU` + `I_HOMOLIB` + `I_ABORTLIB` + `I_DIVORLIB` → `EQUALITY` + `CHOICE` | 性别/性取向/生育权利 | 保守 vs 自由 |
| 发声倾向 | `I_VOICE1` + `I_VOICE2` → `VOICE` | 政治发声意愿 | 顺从 vs 主动 |
| 认识论怀疑 | `DEFIANCE` / `DISBELIEF` / `RELATIVISM` / `SCEPTICISM` | 对权威真理的怀疑 | 绝对 vs 相对 |
| Schwartz 值 | `Y001`(自主)、`Y002`(嵌入)、`Y003`(层级) | Schwartz 三极 | 补充维度 |

**输出特征**:`d_价值 = [sacsecval, resemaval, autonomy, equality, choice, voice, authority, nationalism, devout, defiance, disbelief, relativism, scepticism, schwartz_auto, schwartz_embed, schwartz_hier]`(共 16 维,均已 0-1 标准化)

#### 维度 4:社会规范

WVS 中有大量"可接受行为边界"题项,直接对应社会规范。

| 子维度 | WVS 变量 | 说明 | 编码 |
|---|---|---|---|
| 信任半径 | `Q33P`–`Q41P`(家人/邻里/本国人/外国人信任) | 由近及远的信任衰减 | 0-1 标准化 |
| 通用信任 | `Q42`(信任多数人)、`Q43P`(信任感)、`Q46P`(信任外国人) | 0-1 | |
| 伦理弹性 | `Q176P`–`Q196P`(各种行为可接受度,如逃税、受贿、堕胎、离婚、同性恋) | 规则弹性 | 平均后 0-1 |
| 工作规范 | `Q48`–`Q55P`(工作重要性、闲暇重要性) | 工作伦理 | 0-1 |
| 时间/守时 | (WVS 无直接题项,可用 `Q73P`–`Q82P` 组织信任间接推断) | 间接 | — |

**输出特征**:`d_规范 = [trust_family, trust_neighbor, trust_national, trust_foreign, ethical_flexibility, work_ethic, leisure_ethic]`

#### 维度 5:关系结构

| 子维度 | WVS 变量 | 说明 | 处理 |
|---|---|---|---|
| 婚姻状况 | `Q263` | 1=已婚,2=未婚,3=离异/丧偶 | one-hot |
| 子女数 | `Q264` | 实际子女数 | 连续值(截尾) |
| 家庭规模 | `Q265` | 家庭成员数 | 连续值 |
| 家庭重要性 | `Q1P` | 家庭重要性 0-1 | 直接 |
| 朋友重要性 | `Q2P` | 朋友重要性 0-1 | 直接 |
| 组织参与 | `Q105`–`Q118`(各类组织成员身份) | 社交网络密度 | 计数(0-N) |
| 移民背景 | `Q275` / `Q275R` / `Q276` / `Q276R` / `Q277` / `Q277R` / `Q278` / `Q278R`(本人/父母/祖父母移民) | 代际流动 | one-hot |
| 国家身份观 | `Q253P`–`Q262P`(成为本国人的条件:出生/语言/宗教/公民) | 排他 vs 包容 | 0-1 综合 |

**输出特征**:`d_关系 = [marital_status, n_children, family_size, family_importance, friend_importance, org_density, immigrant_bg, national_identity_exclusivity]`

#### 维度 6:宗教 / 传统

| 子维度 | WVS 变量 | 说明 | 处理 |
|---|---|---|---|
| 宗教派别 | `Q164` | 1-10 大宗派(基督教/伊斯兰/佛教等) | one-hot |
| 宗教重要性 | `I_RELIGIMP` | 越高越不重要 | 0-1 反转 |
| 宗教信仰 | `I_RELIGBEL` | 信仰强度 | 0-1 |
| 宗教实践 | `I_RELIGPRAC` | 实践频率 | 0-1 |
| 宗教组织信任 | `Q6P` | 对宗教组织信任 | 0-1 |
| 传统节日 | (WVS 无直接题项,可由 `Q164` + 国家推断) | — | 衍生 |

**输出特征**:`d_宗教 = [religion_denom_emb, relig_importance, relig_belief, relig_practice, relig_org_trust]`

#### 维度 7:社会经济背景

| 子维度 | WVS 变量 | 说明 | 处理 |
|---|---|---|---|
| 性别 | `Q260` | 1=男,2=女 | 二值 |
| 出生年 | `Q261` | 出生年份 | 连续(可换算年龄) |
| 教育年限 | `Q262` | 受教育年数 | 连续 |
| 教育层级 | `X003R2` | 1=低,2=中,3=高 | ordinal |
| 就业状态 | `Q271` | 1=全职,2=兼职,3=失业,4=退休 | one-hot |
| 职业(ISCO) | `Q266` | ISCO-08 四位码 | 大组 one-hot(10类) |
| 社会阶层 | `Q288` | 1-10 自评阶层 | 0-1 标准化 |
| 收入水平 | `Q289` | 1-10 自评收入等级 | 0-1 标准化 |
| 国家 GDP | `GDPpercap1` / `GDPpercap2` | 人均 GDP | log 变换 |
| 国家 Gini | `giniWB` | 基尼系数 | 直接 |
| 国家 HDI | `hdi` | 人类发展指数 | 直接 |
| 互联网普及率 | `internetusers` | 国家级 | 直接 |

**输出特征**:`d_社会经 = [sex, age, edu_years, edu_level, employment, occupation_group, social_class, income_level, log_gdp, gini, hdi, internet_penetration]`

### 2.3 七维特征总览

| 维度 | 特征数 | 数据来源 | 主要计算 |

| 1 地区 | ~8 | WVS 原生 | 编码 + 坐标 |

| **合计** | **~58** | | |

### 3.2 L1 数据层:清洗与特征工程

#### Step 1: 数据清洗

```python
import pandas as pd
import numpy as np

df = pd.read_csv('WVS_Cross-National_Wave_7_inverted_csv_v6_0.csv', low_memory=False)

# WVS 缺失码统一处理
MISSING_CODES = [-1, -2, -3, -4, -5]
def clean_col(s):
    return s.where(~s.isin(MISSING_CODES))

# 对所有数值列清洗
num_cols = df.select_dtypes(include=[np.number]).columns
df[num_cols] = df[num_cols].apply(clean_col)
```

#### Step 2: 七维特征构造

按第二节映射表,从 WVS 中抽取并构造每维特征。核心代码骨架:

```python
# === 维度 3: 价值观 ===
value_features = df[[
    'SACSECVAL', 'RESEMAVAL',
    'I_AUTHORITY', 'I_NATIONALISM', 'I_DEVOUT',
    'AUTONOMY', 'EQUALITY', 'CHOICE', 'VOICE',
    'DEFIANCE', 'DISBELIEF', 'RELATIVISM', 'SCEPTICISM',
    'Y001', 'Y002', 'Y003'
]].copy()

# === 维度 4: 社会规范 - 信任衰减 ===
trust_cols = ['Q33P','Q34P','Q35P','Q36P','Q37P','Q38P','Q39P','Q40P','Q41P']
df['trust_family']    = df['Q33P'] / 5  # 0-1
df['trust_neighbor']  = df['Q34P'] / 5
df['trust_national']  = df['Q35P'] / 5
df['trust_foreign']  = df['Q36P'] / 5

# 伦理弹性:Q176P-Q196P 平均(Q176P 等为各种行为可接受度 1-10)
ethic_cols = [c for c in df.columns if c.startswith('Q17') and c.endswith('P') or c.startswith('Q18') or c.startswith('Q19')]
df['ethical_flexibility'] = df[ethic_cols].mean(axis=1) / 10

# === 维度 5: 关系结构 - 国家身份排他性 ===
identity_cols = ['Q253P','Q254P','Q255P','Q256P','Q257P','Q258P','Q259P','Q260','Q261','Q262']
# Q253P-Q262: "成为本国人的条件"(出生/语言/宗教/公民等),4=很重要
df['national_identity_exclusivity'] = df[['Q253P','Q254P','Q255P','Q256P','Q257P','Q258P','Q259P']].mean(axis=1) / 4

# === 维度 7: 社会经济 ===
df['age'] = df['A_YEAR'] - df['Q261']
df['log_gdp'] = np.log1p(df['GDPpercap2'])
```

#### Step 3: 标准化与缺失处理

```python
from sklearn.preprocessing import StandardScaler
from sklearn.impute import SimpleImputer

# 合并七维特征
feature_matrix = pd.concat([
    geo_features, lang_features, value_features,
    norm_features, relation_features, relig_features, socio_features
], axis=1)

# 缺失插补(国家内中位数 + 全局中位数)
for col in feature_matrix.columns:
    feature_matrix[col] = feature_matrix[col].fillna(
        feature_matrix.groupby(df['B_COUNTRY_ALPHA'])[col].transform('median')
    ).fillna(feature_matrix[col].median())

# 标准化
scaler = StandardScaler()
X = scaler.fit_transform(feature_matrix)
```

### 3.3 L2 模型层:文化画像建模

#### Step 4: 文化原型发现

采用三种方法对比:

| 方法 | 优势 | 适用场景 |
|---|---|---|
| **K-Means** | 简单、可解释、硬分配 | 初版原型库 |
| **GMM(高斯混合)** | 软分配、概率分布 | 推荐主方案 |
| **HDBSCAN** | 自动确定簇数、发现噪声点 | 探索性分析 |

```python
from sklearn.mixture import GaussianMixture

# GMM 软分配:每个个体属于每个文化原型的概率
n_prototypes = 12  # 通过 BIC 选择
gmm = GaussianMixture(n_components=n_prototypes, covariance_type='full', random_state=42)
prototype_labels = gmm.fit_predict(X)
prototype_probs = gmm.predict_proba(X)  # 软分配矩阵

# 文化原型画像:每个原型的特征均值
prototype_profiles = pd.DataFrame(
    gmm.means_, columns=feature_matrix.columns
)
```

#### Step 5: 个体软分配与情境条件分布

**关键创新:同一人在不同情境下的子画像激活**

WVS 中的"工作重要性 vs 家庭重要性"、"对家人信任 vs 对外国人信任"等成对题项,可用于推断情境条件分布:

```python
# 计算每个个体的"情境弹性"
df['context_flexibility'] = (
    abs(df['Q48']/10 - df['Q1P']) +      # 工作 vs 家庭
    abs(df['Q33P']/5 - df['Q36P']/5) +    # 家人信任 vs 外国人信任
    abs(df['Q74P']/10 - df['Q82P']/10)   # 本国组织 vs 国际组织信任
) / 3
```

输出:每个个体得到

- `prototype_probs`:12 维软分配向量(属于每个文化原型的概率)
- `context_flexibility`:情境弹性分数(越高越能在不同情境切换文化模式)

#### Step 6: 国家级文化分布

每个国家不再是单一标签,而是 **文化原型的概率分布**:

```python
country_culture_dist = pd.DataFrame(prototype_probs, columns=[f'P{i}' for i in range(12)])
country_culture_dist['country'] = df['B_COUNTRY_ALPHA'].values
country_profile = country_culture_dist.groupby('country').mean()
```

输出示例(假设性):

| 国家 | P0(传统宗教型) | P1(世俗自主型) | P2(集体主义型) | ... |
|---|---|---|---|---|
| CHN | 0.15 | 0.42 | 0.28 | ... |
| USA | 0.22 | 0.35 | 0.18 | ... |
| EGY | 0.68 | 0.05 | 0.20 | ... |

## 四、与经典文化理论的映射

### 4.1 与 Hofstede 维度的对应

| Hofstede 维度 | 本方案对应特征 | WVS 来源 |
|---|---|---|
| 个人主义 vs 集体主义 | `AUTONOMY` + `EQUALITY` + `CHOICE` | `I_INDEP`/`I_IMAGIN`/`I_NONOBED` 等 |
| 权力距离 | `I_AUTHORITY` + `I_TRUSTARMY`/`I_TRUSTPOLICE`/`I_TRUSTCOURTS` | 直接 |
| 不确定性规避 | `SCEPTICISM`(反转)+ `RELATIVISM` | `SCEPTICISM` |
| 长期导向 | (WVS 无直接对应,可用 `Q48`-`Q55` 工作伦理近似) | 间接 |
| 放纵 vs 克制 | `CHOICE` + `I_HOMOLIB`/`I_ABORTLIB`/`I_DIVORLIB` | 直接 |

### 4.2 与 Hall 高/低语境的对应

WVS 无直接"沟通风格"题项,但可通过以下间接推断:

- **信任半径衰减**(`trust_family - trust_foreign` 差值大 → 高语境倾向)
- **伦理弹性**(高弹性 → 低语境倾向)
- **国家身份排他性**(高排他 → 高语境倾向)

### 4.3 与 Triandis 个人主义/集体主义的对应

- **垂直集体主义** ↔ 高 `I_AUTHORITY` + 高 `I_NATIONALISM` + 低 `AUTONOMY`
- **水平个人主义** ↔ 高 `EQUALITY` + 高 `VOICE` + 高 `AUTONOMY`

### 5.2 情境适配建议(用于 AI 对话)

基于文化指纹,动态调整交互风格:

| 文化特征 | 高值适配策略 | 低值适配策略 |
|---|---|---|
| `I_AUTHORITY`(权力距离) | 礼貌、间接、尊重层级 | 直接、平等、挑战性 |
| `AUTONOMY`(个人主义) | 强调个人选择、隐私 | 强调群体、家庭、关系 |
| `trust_foreign`(开放度) | 谨慎、本地化例子 | 开放、跨文化例子 |
| `ethical_flexibility` | 严格规则、明确边界 | 灵活、情境化判断 |
| `context_flexibility` | 固定语调 | 按情境切换语调 |

## 七、局限性与改进方向

### 7.1 当前局限

| 局限 | 影响 | 缓解方案 |
|---|---|---|
| **语言维度薄弱** | WVS 仅记录访谈语言,无母语/使用语言 | 外接 Ethnologue / 用户自报 |
| **无个体行为数据** | WVS 是态度量表,非行为日志 | 后续接入用户行为数据补充 |
| **国家级指标噪声** | GDP/HDI 等为国家级,个体内无变异 | 作为层级变量,用多层模型 |
| **无纵向数据** | Wave 7 为单一时点,无法看演化 | 结合 Wave 1-6 做时间序列 |
| **政党模块高缺失** | GPS 系列缺失率 96% | 仅用于投票子样本分析 |

### 7.2 后续扩展方向

1. **多源数据融合**:WVS + 世界价值观调查时间序列 + GSS + ESS,构建跨时段文化演化模型
2. **行为数据接入**:接入社交媒体语言风格、消费行为等,补充 WVS 缺失的行为层
3. **大模型文化适配**:将文化指纹作为 prompt 上下文,使 LLM 输出符合用户文化特征
4. **动态文化追踪**:对同一群体做多波次调查,建立文化演化轨迹
