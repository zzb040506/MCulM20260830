## 七、数据使用建议

1. **跨国比较必需权重**
   - 使用 `W_WEIGHT`(设计权重)和 `S018`(等权国家权重)进行跨国加权。
   - 个人层级分析可用 `PWGHT`。

2. **国家级指标直接可用**
   - V-Dem(`v2x_*`)、Freedom House(`fh*`)、世行 WGI(`td_*`)、BTI(`bti*`)已合并到数据集中,无需另行匹配。

3. **Inglehart 价值观指数**
   - `I_*` 系列已 0–1 标准化,可直接用于回归、聚类、因子分析。
   - 主要维度:`I_AUTHORITY`(权威)、`I_NATIONALISM`(民族主义)、`I_DEVOUT`(虔诚)、`AUTONOMY`(自主)、`EQUALITY`(平等)、`CHOICE`(选择)、`VOICE`(发声)。

4. **政党模块慎用**
   - 缺失率约 96%,仅适用于投票给已编码政党的子样本。
   - 可结合 `Partyname / Partyabb / GPS_V*` 做选民-政党匹配分析。

5. **中国子样本**
   - 共 3,036 人,2018 年调查,样本量充足,可单独做中国价值观画像。

6. **缺失值清理**
   - 分析前务必过滤负值编码(`-1 / -2 / -4 / -5`)。
   - 推荐清洗规则:`df = df[df[col] >= 0]`。
