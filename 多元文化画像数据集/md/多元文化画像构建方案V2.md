# 多元文化画像构建方案

## 一、项目背景与动机

### 1.1 问题意识:为什么需要重新定义"文化"?

人类正在进入一个**文化身份高度流动**的时代。全球化、移民、数字媒体、远程协作让个体的文化实践远超其国籍边界:

- 一个出生在上海陆家嘴、留美归来的 90 后工程师,与一位长居云南村寨的 70 后农民,虽然同属"中国",但在沟通方式、权力距离、信任半径、宗教态度上差异巨大。
- 相反,新加坡华人、加州硅谷工程师、柏林艺术院校学生,可能比他们与本国同胞在文化习惯上更接近。
- 文化不再是静态的国别属性,而是一个随情境、生命周期、社会流动不断演化的动态向量。

然而,当前主流的跨文化研究、AI 交互、产品设计,仍普遍采用**"国籍即文化"**的粗颗粒代理:

| 场景 | 典型做法 | 缺陷 |
|---|---|---|
| 跨文化学术研究 | "中美对比""东西方对比" | 组内方差被国籍均值掩盖 |
| AI 对话系统 | 按用户国别切换问候语/例子 | 同国异质用户被错误归类 |
| 全球化产品设计 | 按国家切版本(美版/日版/中版) | 跨域同质群落被割裂 |
| 国际人才管理 | 按护照国别归档文化档案 | 移民/多元文化身份被忽略 |

**根本问题**:"中国""美国"只是一个粗糙的代理变量(proxy),用它替代"文化"会引入大量误差和偏见。我们需要从**"你是哪国人"(确定性、二值、静态)** 升级到 **"你在什么文化情境下,如何思考与行动"(概率性、连续、动态)**。

### 1.2 核心命题

把文化从"一张国籍标签"重新定义为"一个高维、概率、结构化的特征空间":

$$
C_i = [d_{\text{地区}}, d_{\text{语言}}, d_{\text{价值}}, d_{\text{规范}}, d_{\text{关系}}, d_{\text{宗教}}, d_{\text{社会经}}]
$$

每个维度不是单一取值,而是**概率分布/特征向量**,使得:

- 同一个体在不同情境下可"激活"不同文化子画像(如工作中偏向西方规范,家庭中偏向传统规范)
- 一个群体呈现**统计分布**而非同质整体(如"日本样本在不确定性规避维度上均值为 75,标准差为 12")
- 系统可做**软匹配**:当一个用户表达某句话时,不是问"他是哪国人",而是问"他的这句话最接近哪个文化特征向量组合"

### 1.3 为什么选择 WVS 作为多元文化画像的数据基础?

构建文化特征向量,首要前提是获得**跨国、多维、个体层级**的文化测量数据。我们对主流跨文化数据源做了系统评估:

#### 1.3.1 候选数据源对比

| 数据源 | 样本规模 | 国家覆盖 | 维度丰富度 | 个体层级 | 时间跨度 | 公开可用 | 价值观理论体系 |
|---|---|---|---|---|---|---|---|
| **WVS(世界价值观调查)** | **97,220** | **66** | **611 变量** | **是** | 1981–2023(7 波) | **是** | **Inglehart-Welzel** |
| Hofstede 文化维度 | 国家级均值 | ~110 | 6 维 | **否**(仅国家分) | 横截面 | 部分付费 | Hofstede |
| GLOBE 研究 | 17,300 | 62 | ~50 题 | 是 | 单波 | 部分公开 | GLOBE 9 维 |
| ESS(欧洲社会调查) | ~50,000 | 30+ | ~200 题 | 是 | 2002–至今 | 是 | 无统一理论 |
| GSS(美国综合社会调查) | ~60,000 | 1(美国) | ~500 题 | 是 | 1972–至今 | 是 | 无统一理论 |
| 世界银行/UN 指标 | 国家级 | ~200 | 经济社会 | **否** | 年度 | 是 | 无 |

#### 1.3.2 WVS 的六大不可替代优势

经过对比,WVS 是构建多元文化画像**最合适的原始数据基础**,原因如下:

| # | 优势 | 说明 | 对文化画像的意义 |
|---|---|---|---|
| 1 | **样本规模最大** | 97,220 个个体,是 GLOBE 的 5.6 倍 | 支持国家级分布建模,而非仅均值 |
| 2 | **国家覆盖最广** | 66 国,涵盖发达/发展中/转型经济体 | 跨文化比较的外部效度高 |
| 3 | **变量最丰富** | 611 个变量,远超 ESS/GSS 的核心模块 | 可构造 7 维 ~91 个特征 |
| 4 | **个体层级数据** | 每个受访者有完整问卷,非国家级均值 | 可做个体聚类与软分配 |
| 5 | **理论体系成熟** | 内嵌 Inglehart-Welzel 世俗-传统/生存-自我表达二维体系 | 价值观维度已 0-1 标准化,可直接建模 |
| 6 | **外部指标已合并** | V-Dem/Freedom House/WGI/BTI/世行宏观已按国家合并 | 无需额外数据匹配,可直接做层级分析 |

#### 1.3.3 关键决策因素

**为什么不是 Hofstede?**
- Hofstede 仅提供 6 个国家维度得分,无个体数据,无法做个体画像或分布建模。
- 维度数过少(仅 6),无法构造高维文化向量。

**为什么不是 GLOBE?**
- 样本量较小(17,300),且部分国家仅企业经理样本,代表性有限。
- 9 个维度虽多,但变量数远少于 WVS 的 611 个。

**为什么不是 ESS/GSS?**
- ESS 仅覆盖欧洲(~30 国),地理范围受限。
- GSS 仅美国单国,无跨国比较能力。
- 两者均无内嵌的统一价值观理论体系(如 Inglehart-Welzel)。

**为什么 WVS 是最佳选择?**
- 它同时满足:**大样本 + 跨国 + 个体层级 + 多维 + 理论体系 + 外部指标合并**,是唯一能同时满足"文化特征向量"六项核心需求的数据源。
- Inglehart-Welzel 理论体系已将核心价值观标准化为 0-1 指数(`I_*` 系列、`SACSECVAL`、`RESEMAVAL`),直接可用,无需重新构造。

#### 1.3.4 WVS 的局限与缓解

| 局限 | 影响 | 缓解方案 |
|---|---|---|
| 无母语/双语能力数据 | 语言维度有限 | 有 `Q272` 家庭语言;可外接 Ethnologue |
| 仅态度量表,无行为日志 | 缺行为层 | 后续接入行为数据补充 |
| 单一时点(Wave 7) | 无法看演化 | 结合 Wave 1-6 做时间序列 |
| 部分模块仅部分国家(MENA/WEE) | 覆盖不均 | 作为可选扩展维度 |

> **结论**:WVS Wave 7 是当前构建"多元文化画像"最可行、最完整、最可靠的原始数据基础。其 97,220 × 611 的数据规模、66 国覆盖、Inglehart-Welzel 理论体系、以及已合并的国家级治理指标,使其成为本项目的唯一选择。

### 1.4 项目目标

| 层级 | 目标 | 交付物 |
|---|---|---|
| **L1 数据层** | 基于 WVS Wave 7 构建可计算的文化特征库 | 97,220 × 91 维 清洗后数据集 |
| **L2 模型层** | 训练文化画像模型(聚类、降维、分布建模) | 文化原型库 + 个体软分配 |
| **L3 应用层** | 提供 AI 交互/产品设计/研究的接口 | 文化指纹查询 + 情境适配建议 |

### 1.5 预期影响

| 应用领域 | 传统做法 | 本方案做法 |
|---|---|---|
| **AI 交互** | 按国别切换问候语/例子 | 按文化原型概率分布动态调整语气、说服策略 |
| **跨文化研究** | "中美对比"宏大叙事 | "长三角工程师 vs 硅谷工程师"精细比较 |
| **产品设计** | 按国家切版本 | 按文化特征聚类设计版本(微调式本地化) |
| **国际人才管理** | 按护照国别归档 | 按文化指纹匹配团队/岗位 |

## 二、七维度变量映射表

### 维度 1:地区 / 地理

| 子维度 | WVS 变量 | Label(codebook 原文) | 处理 |
|---|---|---|---|
| 国家(ISO-3) | `B_COUNTRY_ALPHA` | ISO 3166-1 alpha-3 country code | one-hot / embedding |

### 维度 2:语言

| 子维度 | WVS 变量 | Label | 处理 |
|---|---|---|---|
| 访谈语言 | `S_INTLANGUAGE` | Language in which interview was conducted | one-hot / embedding |

| **家庭语言** | `Q272` | Language at home | one-hot / embedding ⭐ |

### 3.2 L1 数据层:清洗与特征工程

#### Step 1: 数据清洗

```python
import pandas as pd
import numpy as np

df = pd.read_csv('WVS_Cross-National_Wave_7_inverted_csv_v6_0.csv', low_memory=False)

# WVS 缺失码统一处理
MISSING_CODES = [-1, -2, -3, -4, -5]
num_cols = df.select_dtypes(include=[np.number]).columns
df[num_cols] = df[num_cols].where(~df[num_cols].isin(MISSING_CODES))
```

#### Step 2: 七维特征构造

```python
# === 维度 1: 地区 ===
geo_features = df[[
    'B_COUNTRY_ALPHA', 'N_REGION_ISO', 'H_URBRURAL',
    'G_TOWNSIZE', 'H_SETTLEMENT', 'O1_LONGITUDE', 'O2_LATITUDE'
]].copy()

# === 维度 2: 语言 ===
lang_features = df[['S_INTLANGUAGE', 'LNGE_ISO', 'Q272']].copy()
# 家庭语言与国语是否一致(衍生)
lang_features['lang_mismatch'] = (
    df.groupby('B_COUNTRY_ALPHA')['Q272'].transform(lambda x: x != x.mode().iloc[0] if not x.mode().empty else False)
).astype(int)

# === 维度 3: 价值观(已 0-1 标准化) ===
value_features = df[[
    'SACSECVAL', 'RESEMAVAL',
    'I_AUTHORITY', 'I_NATIONALISM', 'I_DEVOUT',
    'I_TRUSTARMY', 'I_TRUSTPOLICE', 'I_TRUSTCOURTS',
    'I_NORM1', 'I_NORM2', 'I_NORM3',
    'AUTONOMY', 'EQUALITY', 'CHOICE', 'VOICE',
    'DEFIANCE', 'DISBELIEF', 'RELATIVISM', 'SCEPTICISM',
    'Y001', 'Y002', 'Y003'
]].copy()

# === 维度 4: 社会规范 ===
# 4.1 信任半径
trust_cols = ['Q57P','Q58P','Q59P','Q60P','Q61P','Q62P','Q63P']
norm_features = df[trust_cols].copy()
norm_features.columns = [
    'trust_general','trust_family','trust_neighbor','trust_acquaintance',
    'trust_stranger','trust_other_religion','trust_foreign'
]
# 信任衰减梯度
norm_features['trust_decay'] = norm_features['trust_family'] - norm_features['trust_foreign']

# 4.2 机构信任(均值)
inst_trust = [f'Q{c}P' for c in range(64,90) if f'Q{c}P' in df.columns]
norm_features['institutional_trust'] = df[inst_trust].mean(axis=1)

# 4.3 伦理弹性
justifiable_cols = [f'Q{c}' for c in range(177,196) if f'Q{c}' in df.columns]
norm_features['ethical_flexibility'] = df[justifiable_cols].mean(axis=1) / 10

# 4.4 工作伦理
norm_features['work_ethic'] = df[['Q39P','Q40P','Q41P']].mean(axis=1)

# 4.5 政府权力接受度
norm_features['gov_power_acceptance'] = df[['Q196P','Q197P','Q198P']].mean(axis=1)

# === 维度 5: 关系结构 ===
relation_features = pd.DataFrame()
relation_features['marital_status'] = df['Q273']
relation_features['n_children'] = df['Q274']
relation_features['household_size'] = df['Q270']
relation_features['live_with_parents'] = df['Q271']
relation_features['family_importance'] = df['Q1P']
relation_features['friend_importance'] = df['Q2P']
relation_features['leisure_importance'] = df['Q3P']

# 移民背景(0-3 代)
immigrant_cols = ['Q263','Q264','Q265']
relation_features['immigrant_generations'] = df[immigrant_cols].apply(lambda x: (x==1).sum(), axis=1)

# 组织参与计数(0-12)
org_cols = [f'Q{c}R' for c in range(94,106) if f'Q{c}R' in df.columns]
relation_features['org_density'] = df[org_cols].apply(lambda x: (x>0).sum(), axis=1)

# 认同半径(世界认同 - 本地认同)
relation_features['identity_radius'] = df['Q259P'] - df['Q255P']

# 自主 vs 服从(儿童品质)
relation_features['autonomy_vs_obedience'] = (df['Q8P'] + df['Q11P']) - (df['Q7P'] + df['Q17P'])

# 排他性指数(邻里)
neighbor_cols = [f'Q{c}P' for c in range(18,27) if f'Q{c}P' in df.columns]
relation_features['exclusion_index'] = df[neighbor_cols].mean(axis=1)

# === 维度 6: 宗教 ===
relig_features = pd.DataFrame()
relig_features['god_importance'] = df['Q164'] / 10  # 1-10 量表
relig_features['believe_god'] = df['Q165P']
relig_features['believe_afterlife'] = df['Q166P']
relig_features['believe_hell'] = df['Q167P']
relig_features['believe_heaven'] = df['Q168P']
relig_features['religion_denomination'] = df['Q289']  
relig_features['service_attendance'] = df['Q171P']
relig_features['church_trust'] = df['Q64P']
relig_features['relig_importance'] = df['I_RELIGIMP']
relig_features['relig_belief'] = df['I_RELIGBEL']
relig_features['relig_practice'] = df['I_RELIGPRAC']

# === 维度 7: 社会经济 ===
socio_features = pd.DataFrame()
socio_features['sex'] = df['Q260']
socio_features['age'] = df['Q262']  
socio_features['edu_isced'] = df['Q275']  
socio_features['edu_3group'] = df['Q275R']
socio_features['employment'] = df['Q279']  
socio_features['occupation'] = df['Q281']  
socio_features['social_class'] = df['Q287P']  
socio_features['income_level'] = df['Q288'] / 10  
socio_features['ethnicity'] = df['Q290']
socio_features['log_gdp'] = np.log1p(df['GDPpercap2'])
socio_features['gini'] = df['giniWB']
socio_features['hdi'] = df['hdi']
socio_features['internet_users'] = df['internetusers']
```

#### Step 3: 标准化与缺失处理

```python
from sklearn.preprocessing import StandardScaler

# 合并七维特征
feature_matrix = pd.concat([
    geo_features, lang_features, value_features,
    norm_features, relation_features, relig_features, socio_features
], axis=1)

# 仅保留数值列用于建模(分类变量单独 embedding)
numeric_cols = feature_matrix.select_dtypes(include=[np.number]).columns
feature_numeric = feature_matrix[numeric_cols].copy()

# 缺失插补:国家内中位数 → 全局中位数
for col in feature_numeric.columns:
    feature_numeric[col] = feature_numeric[col].fillna(
        feature_numeric.groupby(df['B_COUNTRY_ALPHA'])[col].transform('median')
    ).fillna(feature_numeric[col].median())

# 标准化
scaler = StandardScaler()
X = scaler.fit_transform(feature_numeric)
```

### 3.3 L2 模型层

#### Step 4: 文化原型发现(GMM 软分配)

```python
from sklearn.mixture import GaussianMixture

n_prototypes = 12  # 通过 BIC 选择
gmm = GaussianMixture(n_components=n_prototypes, covariance_type='full', random_state=42)
prototype_labels = gmm.fit_predict(X)
prototype_probs = gmm.predict_proba(X)  # 软分配矩阵

# 文化原型画像
prototype_profiles = pd.DataFrame(gmm.means_, columns=feature_numeric.columns)
```

#### Step 5: 情境弹性

```python
# 计算每个个体的"情境弹性"
# 工作 vs 家庭(Q41P 工作 should come first vs Q1P 家庭重要性)
# 家人信任 vs 外国人信任(Q58P vs Q63P)
# 本国组织 vs 国际组织信任(Q71P 政府 vs Q83P UN)
df['context_flexibility'] = (
    abs(df['Q41P'] - df['Q1P']) +          # 工作 vs 家庭
    abs(df['Q58P'] - df['Q63P']) +          # 家人 vs 外国人信任
    abs(df['Q71P'] - df['Q83P'])            # 本国政府 vs UN
) / 3
```

#### Step 6: 国家级文化分布

```python
country_culture_dist = pd.DataFrame(
    prototype_probs, columns=[f'P{i}' for i in range(n_prototypes)]
)
country_culture_dist['country'] = df['B_COUNTRY_ALPHA'].values
country_profile = country_culture_dist.groupby('country').mean()
```

## 四、与经典文化理论的映射

### 4.1 与 Hofstede 维度的对应

| Hofstede 维度 | 对应特征 | WVS 来源 |
|---|---|---|
| 个人主义 vs 集体主义 | `AUTONOMY` + `EQUALITY` + `CHOICE` + `autonomy_vs_obedience` | `I_INDEP`/`I_IMAGIN`/`I_NONOBED` + `Q8P`/`Q11P`/`Q7P`/`Q17P` |
| 权力距离 | `I_AUTHORITY` + `I_TRUSTARMY`/`I_TRUSTPOLICE`/`I_TRUSTCOURTS` | 直接 |
| 不确定性规避 | `SCEPTICISM`(反转)+ `RELATIVISM` | 直接 |
| 长期导向 | `Q13P`(节俭)+ `Q14P`(毅力)+ `Q9P`(勤奋) | 儿童品质 |
| 放纵 vs 克制 | `CHOICE` + `I_HOMOLIB`/`I_ABORTLIB`/`I_DIVORLIB` + `ethical_flexibility` | 直接 |

### 4.2 与 Hall 高/低语境的对应

- **信任半径衰减**(`trust_family - trust_foreign` 差值大 → 高语境倾向)
- **伦理弹性**(高弹性 → 低语境倾向)
- **排他性指数**(高排他 → 高语境倾向)
- **认同半径**(`world_identification - local_identification` 低 → 高语境倾向)

### 4.3 与 Triandis 个人主义/集体主义的对应

- **垂直集体主义** ↔ 高 `I_AUTHORITY` + 高 `I_NATIONALISM` + 高 `exclusion_index` + 低 `AUTONOMY`
- **水平个人主义** ↔ 高 `EQUALITY` + 高 `VOICE` + 高 `AUTONOMY` + 高 `identity_radius`

## 七、局限性与改进方向

### 7.1 当前局限

| 局限 | 影响 | 缓解方案 |
|---|---|---|
| **语言维度仍有限** | 有 `Q272` 家庭语言,但仍无双语能力/使用频率 | 外接 Ethnologue / 用户自报 |
| **无个体行为数据** | WVS 是态度量表,非行为日志 | 接入社交媒体/消费行为数据 |
| **国家级指标噪声** | GDP/HDI 为国家级,个体内无变异 | 作为层级变量,用多层模型 |
| **无纵向数据** | Wave 7 单一时点 | 结合 Wave 1-6 做时间序列 |
| **政党模块高缺失** | GPS 系列缺失率 96% | 仅用于投票子样本分析 |
| **MENA/WEE 模块局限** | 仅部分国家采集 | 作为可选扩展维度 |

### 7.2 方案亮点

1. **变量映射准确**:基于 codebook 实际定义精确映射,确保每个变量含义无误
2. **特征丰富度**:共 ~91 维,覆盖 7 个文化维度
3. **新增高价值变量**:家庭语言、组织参与、邻里排斥、儿童品质、地域认同
4. **理论映射更严谨**:Hofstede 长期导向可用儿童品质(节俭/毅力/勤奋)刻画
5. **情境弹性题项修正**:基于实际题项定义计算

### 7.3 后续扩展方向

1. **多源数据融合**:WVS + GSS + ESS,跨时段文化演化
2. **行为数据接入**:社交媒体语言风格、消费行为
3. **大模型文化适配**:文化指纹作为 prompt 上下文
4. **动态文化追踪**:多波次调查建立演化轨迹
